# Notes

Use this folder for knowledge that applies across multiple projects. Keep project-specific decisions and findings in that project's own `docs/` folder.

| File | What belongs here |
|---|---|
| `learning-log.md` | Dated record of study sessions and progress |
| `concepts.md` | General data-engineering and Databricks concepts |
| `spark-sql.md` | Spark SQL syntax, queries, functions, and examples |
| `pyspark.md` | PySpark DataFrame operations and patterns |
| `delta-lake.md` | Delta tables, transactions, time travel, and optimisation |
| `databricks-platform.md` | Workspace, compute, catalogs, jobs, notebooks, and platform notes |
| `troubleshooting.md` | Errors, causes, fixes, and lessons learned |

Suggested note style: explain the concept in your own words, add a small example, explain when it is useful, and record any gotchas.
