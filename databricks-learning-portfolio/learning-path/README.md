# Learning Path

Use this as a flexible checklist, not a rigid syllabus. Mark a topic complete only after you can explain it and demonstrate it in a notebook.

## 1. Platform fundamentals
- [ ] Navigate the Databricks workspace
- [ ] Understand notebooks and supported languages
- [ ] Understand compute and session lifecycle
- [ ] Connect a Git repository
- [ ] Read data from a provided or public source

## 2. SQL and data exploration
- [ ] SELECT, WHERE, ORDER BY
- [ ] Aggregations and GROUP BY
- [ ] Joins and set operations
- [ ] CTEs and subqueries
- [ ] Window functions
- [ ] Data quality checks

## 3. Apache Spark and PySpark
- [ ] DataFrames and schemas
- [ ] Transformations and actions
- [ ] Lazy evaluation
- [ ] Joins, aggregations, and windows
- [ ] Partitions and shuffles
- [ ] Read and write common formats

## 4. Delta Lake and lakehouse
- [ ] Create Delta tables
- [ ] ACID transactions
- [ ] MERGE / upsert
- [ ] Time travel
- [ ] Schema enforcement and evolution
- [ ] Optimisation basics

## 5. Data pipelines
- [ ] Build a repeatable ETL/ELT pipeline
- [ ] Separate raw, cleaned, and curated layers
- [ ] Add validation and logging
- [ ] Handle incremental loads
- [ ] Orchestrate tasks with Jobs / Workflows

## 6. Portfolio projects
- [ ] Complete one SQL exploration project
- [ ] Complete one PySpark transformation project
- [ ] Complete one end-to-end pipeline project
- [ ] Document trade-offs, limitations, and results
